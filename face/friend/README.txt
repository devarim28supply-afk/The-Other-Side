Other Side faces
================

You see the other person's webcam on their character.
They see your webcam on you. Your own camera stays off your screen.
Talking still uses the game's own voice.

Both of you do this:

1. Quit The Other Side completely.
2. Unzip this folder anywhere. Replace an older OtherSideFaces folder if you have one.
3. Double-click Install FacePlate.cmd. Wait until it says FacePlate is installed.
4. Start The Other Side and get into a round together.
5. Double-click Start Other Side Faces.cmd. Allow the camera if Windows asks.

The picture is the face plate. It turns with their head. The back of the head covers it.
Right Arrow changes the shape:

- Tap it: hex for 20 seconds, then it returns to the diamond.
- Hold it for 1 second: the hex stays locked.
- Tap it while the hex is locked: back to the diamond.

The room pass in this folder lasts 30 days from the day this zip was made.
After that, ask for a new zip.

To quit, end TosFace in Task Manager. The picture has no close button.
If Windows says the WebView2 runtime is missing, install Microsoft Edge
WebView2 (Evergreen) and run the start script again.
